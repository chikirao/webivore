# WEBIVORE — chikirao / vault

3D-игра, в которой белый заяц собирает страницу сайта в многослойный бумажный шар. Вход — иллюстрация и URL; после прохождения можно сохранить настоящий вращающийся трофей как квадратную GIF.

## Запуск

Node.js 22.12+ (проверено на Node 24):

```sh
npm install
npx playwright install chromium
npm run dev
```

Игра: http://localhost:5174/. API: 127.0.0.1:3001. Порт frontend задан в vite.config.ts. Если API уже запущен отдельно, достаточно `npx vite --host 127.0.0.1 --port 5174`. Демо работает без загрузки внешнего сайта.

## Управление

- WASD / стрелки — ходьба относительно камеры.
- Перетаскивание — вращение и наклон камеры.
- Правая кнопка или Shift + перетаскивание — панорамирование.
- Q / E — поворот; колесо и + / − — масштаб.
- Space — следить за персонажем; R / Reset — сброс камеры.
- Escape / Pause — пауза. Потеря фокуса также приостанавливает игру.
- Touch: левая половина игрового окна — ходьба, правая — камера.

## Подбор и рост

Крупные фрагменты **не блокируют ходьбу**. Их можно пересекать, но подбор разрешён только при достаточном размере шара. Персонаж начинает с пустыми руками.

С ростом часть соседних небольших фрагментов объединяется при подборе. Пространственная сетка ограничивает поиск соседей, площадь определяет относительный размер фрагмента, а стабильный выбор оставляет часть мелочи одиночной. Одна группа содержит до 18 исходных элементов и создаёт одну летящую порцию, один звук и ограниченный эффект. Все исходные части точно учитываются в массе, очках и прогрессе и стираются отдельно по своим областям. Порог каждого участника проверяется до подбора группы.

Размер имеет конечный бюджет, распределённый до начала игры по всем исходным объектам. Максимальный радиус ограничен 360 игровыми единицами. Все части захваченной страницы остаются собираемыми; лимит размера не ограничивает процент прохождения. Единицы размера условные.

## Постоянные слои

Каждая визуальная порция получает геометрию, глубину и размер в момент подбора. При росте они не меняются, старые слои не удаляются и не выталкиваются на поверхность. Полный пакет из 48 порций распределён по всем восьми секторам и обоим полюсам сферы. Готовой скрытой сферы под бумагой нет.

Каждые 48 порций используют общий меш и атлас. Старые атласы уменьшаются до 256×192, но геометрия сохраняется. Одновременно летят до 32 порций; остальные сразу встраиваются. Количество съеденных исходных фрагментов и количество визуальных порций теперь могут различаться — группа сохраняет текстуры всех своих участников на общем листе.

## Страница

Playwright снимает длинную страницу отдельными прокрученными viewport и склеивает PNG, поэтому нижние экраны не становятся пустыми. Извлекаются прямые текстовые Range, изображения и интерактивные элементы. `partitionPage` назначает видимым пикселям непересекающихся владельцев; остатки CSS-графики и содержимого тоже превращаются в собираемые области.

В мире отображается изменяемая исходная текстура. При подборе стираются только области конкретного объекта. После последнего подбора удаляются слабоконтрастные остатки сглаживания. Финал наступает после сбора всех объектов. Предел высоты захваченной страницы — 9000 px; обрезка обозначается в HUD.

## Маскот, интерфейс и экспорт

Заяц использует отдельные сгенерированные атласы головы и тела: 8 направлений × 3 высоты камеры. Ракурс зависит от камеры относительно направления персонажа. Руки — независимые белые сферы с чёрной обводкой, расположенные у шара. Палитра интерфейса белая/чёрная/красная; вокруг сайта чёрное окружение. Параллакс, курсор с инверсией и плотная Arial-типографика развивают визуальный язык портфолио.

Финал рендерит действительные слои коллекции отдельной камерой. Экспорт: GIF89a, 512×512, 48 кадров по 80 ms, бесконечный цикл, название игры и домен сайта. Палитра и LZW кодируются в Web Worker, без сервиса загрузки файлов. После подготовки скачивание запускается автоматически и остаётся повторная ссылка. Reduced motion отключает декоративные движения и автоматический поворот превью; явно запрошенная GIF остаётся анимированной.

## Проверки

```sh
npm run build
npm test
npx tsx tests/browser3d.ts
node tests/redesign-browser.mjs
node tests/grouped-live-browser.mjs
```

Браузерные проверки требуют работающих серверов. Новый сценарий проверяет демо, начало с пустыми руками, перемещение без преждевременного подбора, интерфейс desktop/mobile, финал и скачивание GIF. Live-сценарий использует настоящие Wikipedia/Hacker News и проверяет 100% сбора, точность массы, уникальность исходных объектов, сохранность ранних слоёв, уменьшение числа визуальных порций и отсутствие оставшегося содержимого на странице. Для ускоренного прохождения тест перемещает персонажа к оставшимся объектам; это не измерение FPS во время ручной игры.

Дополнительные прежние проверки: `npx tsx tests/layers-browser.ts` и `npx tsx tests/live-browser.ts`. Скриншоты, результаты и тестовые GIF сохраняются в `artifacts/`.

## Сеть и ограничения

Разрешены HTTP(S), порты 80/443 и публичные IPv4. Приватные, loopback, metadata, link-local, зарезервированные адреса и IPv6 заблокированы. Каждый ресурс и редирект проверяется, соединение закрепляется на проверенном IP с исходными Host/SNI. Service Workers, WebSockets и скачивания внешней страницы отключены; пользовательские cookies не передаются. Чужой HTML не исполняется в origin игры.

Для VPN fake-IP 198.18/15 используется фиксированный Cloudflare DNS-over-HTTPS endpoint; реальные адреса повторно проверяются. Cloudflare получает запрашиваемые домены.

Лимиты: один browser job, 55 секунд, 180 запросов, 6 MB на ресурс, 24 MB сетевых данных, 40 000 детально просматриваемых DOM-узлов, высота до 9000 px. Содержимое за пределом детального DOM-бюджета покрывается более крупными фрагментами.

Captcha, авторизация, антибот-защита и некоторые SPA могут мешать загрузке. Страница становится снимком; формы и ссылки не интерактивны. Ходьба происходит в плоскости страницы, без прыжков. Портфолио использовано как источник дизайна; его файлы не изменялись, встраивание в будущий vault отдельно не выполнялось.
